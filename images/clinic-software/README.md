راهنمای بارگذاری اسکرین‌شات‌های نرم‌افزار کلینیک
=================================================

این پوشه مسیر تصاویر صفحه:
https://shirazpcrepair.ir/clinic-management-software.html
است.

نام فایل‌ها را دقیقاً به شکل زیر نگه دار تا جایگاه‌های صفحه خودکار پر شوند:

- dashboard.png       تصویر اصلی / نمای کلی برنامه
- patients.png        فهرست یا پرونده بیماران
- visits.png          نوبت‌ها و وضعیت ویزیت
- doctor-finance.png  تب پزشک، عمل و هزینه‌ها
- reports.png         گزارش‌ها و امور مالی
- patient-photos.png  گالری تصاویر پرونده

روش آپلود:
1. از اسکرین‌شات‌های برنامه فایل PNG بگیر.
2. در GitHub repo maziio/pcrepair وارد پوشه images/clinic-software شو.
3. Add file > Upload files را بزن و فایل را با همان نام بالا بارگذاری کن.
4. بعد از انتشار GitHub Pages، تصویر به‌صورت خودکار به‌جای کادر خالی نمایش داده می‌شود.

برای تبلیغ عمومی، فقط از اطلاعات آزمایشی/ساختگی استفاده کن و اطلاعات شناسایی یا عکس واقعی بیماران را نمایش نده.
